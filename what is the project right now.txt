What Is The Project Right Now

Last updated: 2026-06-01

This checkout is an active Linux port of NVDA on the linux-port branch. The
stable Windows implementation remains in the tree, while Linux-specific
platform adapters provide an early native preview path for X11 and Wayland.

The Linux port is not production-ready. It is usable for focused development,
dependency-light automated tests, and real-desktop preview validation.

Current working areas

1. AT-SPI2 accessibility

- Linux accessibility events are translated, coalesced, and dispatched through
  Linux NVDA object wrappers.
- Wrapped objects expose roles, states, names, descriptions, tree navigation,
  screen geometry, hit testing, and baseline AT-SPI text ranges.
- Text support includes caret, selection, character, line, word, sentence, and
  paragraph primitives.

2. Keyboard input on X11 and Wayland

- Linux key names are normalized to the existing NVDA kb: gesture identifiers
  so Windows-compatible NVDA shortcuts can be reused.
- X11 has an initial passive-grab path for NVDA-modifier commands and preview
  browse keys. Unhandled browse keys are replayed to the application. Real
  desktop suppression and pass-through behavior still needs validation.
- Wayland has an initial evdev keyboard-grab and uinput replay path. It requires
  permission to read keyboard devices under /dev/input and write /dev/uinput.
- Both backends fall back explicitly when global capture is unavailable.

3. Focus mode and browse mode

- Focused AT-SPI documents activate a Linux preview document navigator.
- Browse mode supports Up Arrow, Down Arrow, and single-letter quick navigation
  for headings, links, buttons, edit fields, form fields, lists, list items,
  tables, and landmarks.
- Editable controls automatically use focus mode so typing and arrow keys pass
  through to the application.
- NVDA+Space toggles focus mode and browse mode manually while a document is
  active.
- This is an early AT-SPI document-navigation path, not full NVDA virtual-buffer
  parity yet.

4. Native preview commands

The dependency-light preview currently implements these shared NVDA shortcuts:

- NVDA+1: toggle input help
- NVDA+C: report clipboard text, with repeat spelling and descriptions
- NVDA+F2: pass the next key sequence through
- NVDA+F12: report time, then date on repeat
- NVDA+Shift+B: report battery status
- NVDA+T: report active window title
- NVDA+Tab: report focused object
- NVDA+B: read a bounded active accessible tree
- NVDA+H: report native preview command help
- NVDA+Q: exit the Linux preview
- NVDA+Space: toggle focus mode and browse mode inside documents

The full shared global command map is not running end-to-end on Linux yet.
tools/runLinuxShortcutParityAudit.py reports which shared identifiers are
translated and which commands still need shared-runtime integration.

5. Mouse, speech, audio, clipboard, and packaging

- X11 RECORD pointer observation, AT-SPI hit testing, and accessible-object
  mouse tracking are available for validation.
- Wayland pointer capture is still pending.
- Speech uses spd-say first and espeak-ng as a fallback.
- Wave and tone output uses pw-play, paplay, or aplay.
- Clipboard text uses wl-clipboard, xclip, or xsel.
- User-level Linux preview install, uninstall, desktop-entry, and optional
  systemd service artifacts exist under packaging/linux.

Immediate next work

1. Validate X11 command suppression and pass-through replay on a real desktop.
2. Validate Wayland evdev capture and uinput replay with real permissions.
3. Add Wayland pointer observation.
4. Expand focus/browse behavior beyond the initial document navigator,
   including richer forms interaction, review behavior, and embedded objects.
5. Continue moving Linux startup toward the shared NVDA runtime so more
   existing commands execute without native-preview replacements.
6. Add persistent Speech Dispatcher and streaming Linux audio paths.
7. Add brlapi-backed braille and Linux device discovery.

Useful commands

- Run the dependency-light Linux tests:
  python tests/linuxPortUnitRunner.py
- Run preflight:
  python tools/runLinuxPortPreflight.py
- Run the native preview:
  python tools/runLinuxPort.py --native-preview
- Audit shortcut parity:
  python tools/runLinuxShortcutParityAudit.py
- Run bounded release smoke:
  python tools/runLinuxReleaseSmoke.py --strict-capture --duration 30

Known development constraint

Full uv-based test installation can fail on Windows until Microsoft Visual C++
build tools are installed for fast-diff-match-patch. The dependency-light Linux
runner remains the expected validation path for the current port work.
