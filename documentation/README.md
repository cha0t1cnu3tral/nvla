# Documentation Layout for Rewrite

This folder tracks the NVDA rewrite/port documentation without changing the existing project docs.

- `documentation/nvda windows documentation/`: Windows behavior baseline and parity references.
- `documentation/nvda linux documentation/`: Linux port plans, decisions, and current status.

Each of the two areas is split into:

- `dev/`: engineering and implementation material.
- `user/`: user-facing status and migration notes.
